# Sunmarke School Voice Agent

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. Configure `.env`
4. `npx prisma migrate dev --name init`
5. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

### Usage
- Record voice to query the agent.
- Ensure API keys are set in `.env`.
